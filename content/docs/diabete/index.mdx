Une seule fiche pour toute la famille : les insulines du diabète de type 1 et
les antidiabétiques oraux du diabète de type 2, avec pour chacun le
mécanisme, les situations où elles sont utilisées, et ce qu'on redoute —
l'hypoglycémie en tête.

<Callout type="info" title="Une fiche, deux publics">
Le cours de C. Lafay-Chebassier se découpe en deux capsules (anti-diabétiques
1/2 et 2/2) ; elles sont réunies ici en une seule page : les insulines d'abord,
puis les antidiabétiques oraux.
</Callout>
